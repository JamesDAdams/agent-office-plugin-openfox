# agent-office-plugin-openfox

OpenFox Harness plugin for Agent Office.

## Features

- **FloorProvider**: Synchronizes OpenFox projects as floors in Agent Office
- **QueueAdapter**: Bridges Agent Office Kanban tasks with OpenFox task board
- **ServicesProvider**: Manages OpenFox dev servers, logs, and background processes

## Installation & Build

```bash
npm install
npm run build
```

The compiled plugin entry point is emitted at `dist/index.js`.
